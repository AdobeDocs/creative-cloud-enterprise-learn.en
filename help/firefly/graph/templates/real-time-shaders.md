# Real time shaders

Learn how to start with an image and apply three different custom shaders and preview the result in real time. Adjust shader parameters directly on the node rather than re-rendering from scratch. [Open Real time shaders template](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:51848c67-e360-5c40-8eff-8517b3395d54).

[!BADGE Industry examples]{type=Informative tooltip="Industry examples"}

* **Tech** - Build custom stylized shader looks for a 3D product configurator used in an interactive trade show demo.
* **Automotive** - Preview custom paint and material shaders on a vehicle model before a physical prototype exists.
* **Retail** - Test stylized material looks on a 3D product render for a digital shelf display.

>[!TIP]
>
>**Before you start** - For the best results customize this template to your own brand, product, and workflow. Swap in your reference images, prompts, and copy before using any output.
