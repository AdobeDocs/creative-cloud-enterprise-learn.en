# From sketch to clean, editable vector

Learn how to turn a rough sketch into editable vector artwork in Illustrator without building every shape by hand. See how Concept to Vector interprets a mountain sketch, how to clean up the result with the Direct Selection tool, and how Generative Recolor helps you explore color options for an outdoor ad campaign, all while keeping full control over the design.
