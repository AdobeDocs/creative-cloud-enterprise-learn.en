# Turn flat vector art to any angle — without redrawing it

No need to rebuild patterns by hand for every deliverable. Create seamless vector patterns in minutes, not hours. In this tutorial, learn how to use Text to Pattern in Illustrator to explore options, add your own brand artwork to the repeat, and resize the pattern for different applications without changing the layout. Then, build three colorways from one fully editable design, ready for packaging, textiles, displays, and more.
