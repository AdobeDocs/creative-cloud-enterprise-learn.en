# Move vector art into an InDesign layout and package it for handoff

Printer-ready files mean a lot to keep track of: links, bleeds, fonts, and overset text. Learn how to check a print layout for bleed, overset text, and missing fonts or links, and get fixes, by asking the AI Assistant in InDesign. Then verify in Preflight and package everything for handoff.
