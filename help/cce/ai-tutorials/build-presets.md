# Build presets for consistent color across a shoot

Learn how to give a whole photoshoot a consistent look without editing each image one by one. In this tutorial, learn how to build a color preset in Lightroom, then apply that color grade across a batch of images with bulk actions in Firefly. Your files come back in the same format and pixel dimensions as the originals. Watch the tutorial and try it on your next shoot.
